📌 Cakupan Kisi-Kisi Resmi TKA SD Matematika (Pusmendik)

4 Materi Utama • 17 Indikator
1. Bilangan (Soal 1–6)
  • Memahami nilai tempat
  • Operasi hitung (+, −, ×, ÷)
  • Faktor, kelipatan, dan KPK
  • Pecahan, desimal, dan persen
  • Urutan dan perbandingan bilangan
2. Pengukuran (Soal 7–11)
  • Panjang, berat, dan waktu
  • Kecepatan, jarak, dan waktu
  • Pengukuran sudut
  • Satuan baku & konversi satuan
  • Keliling dan luas bangun datar
3. Geometri (Soal 12–16)
  • Bangun datar (segitiga s.d. lingkaran)
  • Sifat-sifat bangun datar
  • Bangun ruang (kubus, balok, tabung, limas)
  • Volume dan luas permukaan
4. Data & Peluang (Soal 17–20)
  • Penyajian data (tabel, diagram batang/lingkaran)
  • Rata-rata (mean), median, dan modus
  • Peluang kejadian sederhana

⚙️ Panduan Integrasi Google Sheets & Google Sites

Rekap otomatis nilai siswa SDN Sucopangepok 03

Langkah 1: Buat Google Spreadsheet & Apps Script

  1. Buka Google Sheets dan buat spreadsheet baru (misal: Rekap Nilai Try Out TKA Kelas 6).
  2. Klik menu Ekstensi (Extensions) > Apps Script.
  3. Hapus seluruh kode yang ada di Code.gs, lalu tempelkan kode Google Apps Script di bawah ini.
  4. Klik Terapkan (Deploy) > Deployment baru (New deployment).
  5. Pilih jenis Aplikasi Web (Web app), atur Execute as: Me, dan Who has access: Anyone (Siapa saja).
  6. Salin URL Aplikasi Web yang dihasilkan, lalu tempelkan ke konstanta const GOOGLE_SCRIPT_URL = "..."; di bagian atas skrip aplikasi ini (atau simpan langsung lewat kolom pengatur di bawah).
Kode Google Apps Script (Code.gs): 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Waktu Submit", "Nama Lengkap", "Nomor Absen",
        "Mata Pelajaran", "Skor Akhir", "Jumlah Benar",
        "Jumlah Salah", "Pelanggaran Anti-Cheat", "Status Pengumpulan"
      ]);
    }
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.waktuSubmit || new Date().toLocaleString("id-ID"),
      data.nama || "-",
      data.absen || "-",
      data.mataPelajaran || "Try Out TKA Kelas 6 SD - Matematika",
      data.skorAkhir,
      data.jumlahBenar,
      data.jumlahSalah,
      data.jumlahPelanggaran,
      data.statusSubmit || "Selesai Normal"
    ]);
    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
